WinGlow 3.2.2 本地测试版

字体：选择 HarmonyOS Sans、思源黑体或苹方，比较前后，点击应用。
软件界面本身使用内置鸿蒙字体。
鸿蒙只有“标准 / 粗”两个选项；调整字重，不改字号。粗使用真实 Bold 字面。
应用时同步设置经典菜单、对话框、标题、状态栏和桌面文字字体。
用过旧版鸿蒙后，仍可重新点击应用，以补上原生界面设置。
三套字体均已内置，无需下载或导入。苹方使用 Regular、Medium、Semibold 三个静态字重。
应用和普通字体还原成功后自动重启资源管理器，桌面和任务栏会短暂消失，资源管理器窗口可能关闭。
请先完成文件复制等操作。其他已打开的应用需重新打开，部分界面仍需要注销。

右键菜单：默认显示桌面类别，可切换文件夹、EXE、图片等右键位置。
紧凑列表中点击名称查看图标、一级/二级菜单和开启/关闭示意，再用开关控制显示。
程序扩展可能一次隐藏多个位置的一组菜单，动态子项不能从注册表完整读取。
列表是可管理的注册项，不等于一次右键中实际显示的项目；部分位于“显示更多选项”。
Breeze 美化：首次开启需要联网下载官方引擎。关闭后注销恢复原菜单。
不要以管理员权限打开应用来启用 Breeze。

基础美化：开关控制快捷方式箭头、盾牌角标、桌面图标文字、桌面图标与扩展名。
隐藏文字不改文件名。盾牌覆盖为实验功能，部分系统可能不生效；不关闭 UAC。

还原：默认字体、还原右键菜单、还原基础美化、撤销最近修改。
普通还原无效时，点击扫描并修复，运行 Windows DISM 和 SFC 并恢复默认字体映射。
期间不要关闭程序。可能需要联网，结束后注销或重启。
扫描退出不等于所有第三方修改已修复，失败请保留修复日志。

备份：%LOCALAPPDATA%\WindowsFontTuner\Backups
修复日志：%LOCALAPPDATA%\WindowsFontTuner\RepairLogs
Shift 启动 / WinGlow.exe --emergency-reset：恢复最近字体修改。
WinGlow.exe --repair-system：界面打不开时运行系统扫描修复。

每次修改前自动保存原值，失败回退。需要系统权限时才提权。
不直接覆盖 Windows 字体文件，不自动注销或重启电脑。
部分 DirectWrite、WinUI、UWP 界面可能不响应字体映射。
“更换前”参考 Windows 当前对话框字体；应用自行选用字体时，实际效果可能不同。
Breeze 自绘菜单的字体与渲染独立，不会自动跟随本工具的字体选择。
安装版与便携版需 Windows 10/11 x64 与系统 WebView2。
Breeze 使用单独的未修改上游引擎；来源与许可证见 licenses。
本地测试版，自动检查通过；真实应用与还原仍需实机验证，未发布 GitHub Release。

一键优化
首页点击“一键优化”：采用鸿蒙粗体，隐藏快捷方式箭头和盾牌角标，自动精简附加菜单，开启 Breeze 菜单美化与透明任务栏（Windows 11）。首次准备 Breeze 需要联网。
成功后点击“撤销优化”，恢复本次优化前的设置。它不会把用户原有的第三方个性化设置全部清空。
发生错误会尝试自动回退；恢复未完成时，保留记录并显示“继续恢复”。字体、菜单、两种角标、引擎自启与透明任务栏独立配置均纳入同次优化备份。重启资源管理器时文件窗口可能关闭，请先完成文件复制。
菜单的“一键精简”可单独使用。Defender 扫描入口、百度/夸克网盘、WorkBuddy、图片转 PDF 等纳入精简；不关闭杀毒防护。隐藏后仍可手动打开。
直接点击桌面、文件夹、图片等分类。带箭头的菜单可展开，子菜单缩进显示，静态子项可单独开关。动态扩展整组开关；共享子项的显示状态在使用该项的菜单中共同生效。
基础美化中的“透明任务栏”单独启用/关闭。已有另一份 TranslucentTB 正在运行时，请先退出它，软件不会关闭或覆盖其他来源的实例。
其他热门工具只列在项目候选文档中，未默认安装。

本次更新
任务栏开启时默认“模糊”并显示任务栏细线，兼顾易读性；再次开启或一键优化使用此默认设置。
一键精简只会隐藏附加项，不会把已手动关闭的菜单重新打开；BitLocker、旧版 Media Player、华硕、ToDesk、英伟达、豆包和 ChatGPT 项目入口纳入精简。这不卸载程序、不修改磁盘加密状态。
菜单图标优先读取真实资源；没有可用图标时使用对应功能图标。
显示文件扩展名开关会自动刷新资源管理器，文件夹窗口可能关闭。快捷方式等系统特别处理的文件类型仍可能隐藏后缀。
移除“隐藏桌面图标文字”选项，旧版本相关修改仍可通过还原基础美化撤销。
备份为操作前自动生成的设置快照，不需要用户选择；备份失败就停止修改。“打开备份”直接打开快照目录。
扫描修复开始前也自动保存本工具管理的设置。备份不是整盘镜像，不能撤销 DISM/SFC 修复的 Windows 文件。
应用刷新资源管理器后重新连接已启用的任务栏与 Breeze；WinGlow 运行期间也检测外部重启并有限重试恢复。关闭 WinGlow 后由上游引擎自身处理资源管理器重启。
