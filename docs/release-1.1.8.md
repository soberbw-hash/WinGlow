# WinGlow 1.1.8

修复经典布局在未验证 Windows 版本上的兼容性判断。Windows 28000 不再允许安装 ExplorerPatcher，已安装用户仍可打开设置或恢复系统任务栏。

经典布局安装与卸载前保护 WinGlow 管理的 Breeze、透明任务栏和动态壁纸，等待桌面稳定后恢复；不在组件安装后额外重启资源管理器。

可选功能的入口改为“经典布局设置”和“壁纸库”。动态壁纸新增应用内选择本地视频或 GIF、暂停、继续、静音、停止入口；高级壁纸库仍由 Lively 提供。

验证：前端构建、Rust 测试和严格 Clippy 检查。开发机 Windows 28000 上发现 ExplorerPatcher 模块引起 Explorer 崩溃，备份后切回系统任务栏，未再次安装不兼容组件。动态壁纸画面和支持版本上的经典布局安装效果仍需真实桌面验收。
