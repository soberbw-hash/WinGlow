# WinGlow 1.1.13

这次更新集中解决桌面字体变小、切换壁纸白屏，以及菜单精简让桌面和壁纸闪断的问题，并将常用设置整理到 WinGlow 内部。

[下载安装包（Windows x64）](https://github.com/soberbw-hash/WinGlow/releases/download/v1.1.13/WinGlow-1.1.13-Setup.exe) · [下载便携版](https://github.com/soberbw-hash/WinGlow/releases/download/v1.1.13/WinGlow-1.1.13-Portable.zip)

- **字体**：修正高 DPI 字号换算与回读校验，同步桌面字体缓存；保留更大的自定义字号，改善 2K / 4K 与不同缩放比例下的体验。
- **右键菜单**：切换、精简与菜单还原不再主动重启资源管理器。规则独立更新，减少 Breeze 脚本重载；菜单还原不影响动态壁纸启动项。
- **动态壁纸**：修复本地资源路径导致的白底文字，点击图片直接切换；一键优化默认启用真实壁纸库轮播，静音、每5分钟切换。新增显示实际开启状态的拨杆，重新开启恢复之前选择。
- **界面与设置**：移除经典布局、首页设置折叠区及多余壁纸播放控制。任务栏默认六种场景统一模糊并显示细线；窗口背景与开始菜单参数在基础美化中调整。
- **恢复与更新**：改进未完成修改的恢复入口、初始化失败重试和文件占用时的保存；升级已完成的旧优化方案，保留原始备份。软件启动检查更新，后台下载并验签，用户点击后安装。

本机升级验收中只刷新了一次桌面，字体大小保持不变，12项壁纸轮播已启用。104项 Rust 测试通过；界面、恢复与更新状态测试，以及安装包签名和校验检查通过。详细范围见[检查记录](https://github.com/soberbw-hash/WinGlow/blob/main/docs/verification-1.1.13.md)。

支持 Windows 10 / 11 x64，部分美化功能需要 Windows 11。菜单、壁纸及部分材质依赖第三方引擎和系统支持；这次本机检查通过不代表所有系统与桌面工具组合都完成了实测。字体首次应用、恢复或更新优化方案可能短暂刷新桌面；菜单精简不会主动重启桌面。

推荐安装版。已有新版客户端可使用软件中的更新入口；从旧系列迁移时请手动安装，保留原备份。附件同时提供更新签名、`latest.json` 和 `SHA256SUMS.txt`。
