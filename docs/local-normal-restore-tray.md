# 普通还原、托盘与移除轮播：本地检查

2026-10-12。本地测试修订，版本暂保持1.1.13，未提交或发布到GitHub，未替换公开发行附件。

- 新增“设置与还原→一键普通还原”。合并默认字体、最早菜单/细节备份、显式删除本工具美化启动项/图标覆盖/独立配置，且将六种经典字体角色明确恢复为Segoe UI标准字重；保留可读及更大的自定义字号，不改显示缩放。最早备份也可能已包含优化，单纯撤销无法充当Windows默认字体恢复。
- 所有注册设置及字体在一个可回退事务中写入；中途写入失败整体回退，失败不清除优化会话，也不重启桌面。成功后清除当前优化会话并统一刷新一次。动态壁纸先保存当前配置，再关闭本工具管理的播放效果。
- 普通还原不运行DISM/SFC，不恢复软件从未记录的外部系统修改。菜单按最早可用备份恢复，不能承诺整个电脑的出厂状态。高级扫描修复保留为独立入口，降低按钮视觉优先级。
- 新增托盘打开/退出、点击叉号隐藏、重复启动打开已有窗口。后台监控在隐藏后继续；正在系统修改时托盘退出受到互斥锁保护。用户选择退出后，字体及菜单的持久设置仍在，独立效果组件不依赖可见主窗口。
- 自动壁纸轮播已移除：界面不显示轮播卡片/间隔，旧IPC请求明确拒绝，新一键优化仅选择一张真实壁纸。旧登录命令保留兼容，启动壁纸引擎后退出，不创建计时进程；旧播放列表无法重新激活计时。手动选图保留。
- 轮播代码没有重启Explorer。固定Lively2.2.1.0[源代码](https://github.com/lively-community/lively/blob/v2.2.1.0/src/Lively/Lively/Core/WinDesktopCore.cs#L264-L272)为兼容WebView2先关闭旧播放器，再加载新播放器，因此现有集成不能保证切换无闪烁。按用户要求删除自动轮播，不伪装为无缝切换。

## 验证

- 格式、所有目标严格Clippy、生产前端与签名NSIS打包通过。110项Rust测试：106通过，4项显式设备测试跳过，0失败。新增默认覆盖旧优化、部分写入失败完整回退、失败不清除会话/不刷新及成功仅刷新一次的回归检查。
- 原生只读检查当前普通还原计划145个槽位，白名单及启动项关闭规则通过，没有执行还原或写入设备设置。
- 浏览器fixture确认普通还原有独立确认入口，取消不发修改请求，继续只调用一次restore_normal、不调用repair_system，完成后解除已优化状态；即使返回旧卡片数据，轮播入口也不显示。
- 原生托盘关闭/隐藏/重新打开测试通过；正式包再次执行--verify-tray通过。安装器返回0，安装EXE与便携EXE归一化bundle marker后逐字节一致。
- 本机已替换为本次测试程序；桌面与开始菜单快捷方式已核对。旧主界面和轮播计时进程已退出，新GUI及窗口材质后台来自本次安装。重复启动退出0，GUI仅有一个实例。
- 安装后桌面和六种字体角色仍为HarmonyOS Sans SC、-18、700，DPI144，没有自动应用普通还原。播放列表已不存在，当前动态壁纸引擎继续运行，没有为了取消轮播而重启Explorer。

**未执行本机完整普通还原**，避免在用户尚未主动选择还原时清除其当前设置。没有重启/注销电脑；菜单实际显示、不同系统组合及还原后的原生效果仍需要用户实际还原验收。当前测试包位于`artifacts/local-restore-tray`；检查截图/报告及原播放列表备份仅留本地，不进入发行附件。
