# WinGlow 1.1.17

- One-click optimization now applies the selected Breeze language, theme, animation, and installed plugin order in the same backup transaction, so undo restores the previous configuration.
- Adds a Breeze settings button that opens Breeze Config's visual settings window directly.
- Streamlines Basic Beautification with expandable taskbar and wallpaper controls, and refreshes Explorer's icon cache after shortcut-arrow changes.
- Uses dark Windows mode with light app mode for built-in dark wallpapers so the taskbar clock stays visible. Custom wallpapers keep the current color settings.
- Shows optimization stages and progress, and includes a double-click launcher for the local development build.
