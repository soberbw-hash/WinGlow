# WinGlow 1.1.1 修复记录

2026-10-10。

## 问题与修复

用户点击“一键精简”后，Windows 提示 WinGlow.exe 指定路径不存在，应用随后错误地提示“修改字体”授权被取消。安装文件本身存在且版本为 1.1.0；失败请求记录为 optimizeMenu。只读检查发现两项路径问题：主进程继承的工作目录包含乱码；从 MSIX 版 Codex 启动时，表面的 LocalAppData 安装位置被虚拟化到包的 LocalCache，提权代理无法使用表面路径。文件句柄确认了实际物理路径，改用物理路径的管理员检查成功。

管理员进程启动现在解析 EXE 的物理路径、转为 Shell 兼容路径，并显式使用经过存在性检查的 EXE 所在目录，不再继承启动器工作目录。Shell 启动失败交由应用显示，避免额外的误导性系统弹窗；取消授权与其他启动错误分别处理，提示不再绑定字体操作。管理员授权和事务备份机制保持有效。

- 新版主界面已重新打开。完整“一键精简”的菜单效果留给用户在软件中验收，本次不自动改动菜单。
