# WinGlow 1.1.16

- Built-in dark live wallpapers use Windows dark mode with light app mode so the taskbar clock remains readable. Imported and library wallpapers keep the current color settings because their brightness is unknown. WinGlow restores the prior color settings when wallpapers are disabled or restored.
- One-click optimization shows its current stage and progress while preparing components, backing up settings, applying changes, refreshing the desktop, and starting visual effects.
- Includes the optional Lively wallpaper engine flow and first-run initialization fix from 1.1.15.
