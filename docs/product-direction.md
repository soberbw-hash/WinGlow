# WinGlow 发展方向

记录日期：2026-10-03。以下为用户确定的产品方向，作为后续开发和功能取舍的依据；具体已实现功能以 README 和验证记录为准。

这个项目会以 **Windows 字体优化** 为核心，继续完善字体替换、渲染效果、预览和恢复体验。

后续会逐步扩展到更多 **Windows 视觉美化与个性化设置**，把字体、界面观感和常用美化选项集中到一个简单、安全、随时可恢复的工具里。

最终希望它成为一个轻量、好用的 **Windows 视觉调节工具**，让用户不用折腾复杂设置，也能把系统调成自己喜欢的样子。

## 开发原则

- 优先完善字体体验，再逐步扩展视觉美化与个性化功能。
- 界面保持极简，让用户直接选择、预览和应用，减少多余信息与操作。
- 每项系统修改都应有可靠的恢复路径；普通还原和必要时的扫描修复体验同样属于核心功能。
- 新功能应服务于轻量、简单、安全、可恢复的产品定位。

## 字体开箱即用要求

2026-10-03 用户补充：默认展示的候选字体应随软件内置，安装后即可预览和应用，不应要求用户另找字体文件。

当前 HarmonyOS Sans 与思源黑体已内置；苹方仍只有导入入口，尚未达到这一要求。苹方内置需要取得字体文件及覆盖随软件分发用途的许可；目前仓库没有此类资源和授权记录。不能将“可从第三方仓库下载”视为已取得字体再分发许可，也不能用其他字体冒充苹方。后续应解决此资源依赖，再完成真正的内置预览与一键应用。
