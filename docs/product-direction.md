# WinGlow 发展方向

2026-10-04 验收补充：删除显示文件扩展名与隐藏桌面图标选项，保留旧备份恢复。菜单重复注册按实际行为合并。精简以前的版本、加密/解密、幻灯片等入口；压缩类保留基本压缩、解压。上述修改验证完成后才发布重做的 1.0.0。

记录日期：2026-10-03。以下为用户确定的产品方向，作为后续开发和功能取舍的依据；具体已实现功能以 README 和验证记录为准。

这个项目会以 **Windows 字体优化** 为核心，继续完善字体替换、渲染效果、预览和恢复体验。

后续会逐步扩展到更多 **Windows 视觉美化与个性化设置**，把字体、界面观感和常用美化选项集中到一个简单、安全、随时可恢复的工具里。

最终希望它成为一个轻量、好用的 **Windows 视觉调节工具**，让用户不用折腾复杂设置，也能把系统调成自己喜欢的样子。

## 开发原则

2026-10-04 用户确认视觉扩展：窗口磨砂、精选开始菜单美化纳入一键优化；ExplorerPatcher 经典布局与 Lively 动态壁纸独立可选。默认样式要清晰、舒适，不把复杂参数交给用户。具体实现与验证边界见 [视觉集成记录](visual-integrations.md)。

- 优先完善字体体验，再逐步扩展视觉美化与个性化功能。
- 界面保持极简，让用户直接选择、预览和应用，减少多余信息与操作。
- 每项系统修改都应有可靠的恢复路径；普通还原和必要时的扫描修复体验同样属于核心功能。
- 新功能应服务于轻量、简单、安全、可恢复的产品定位。

## 字体开箱即用要求

2026-10-03 用户补充：默认展示的候选字体应随软件内置，安装后即可预览和应用，不应要求用户另找字体文件。

3.1.3 本地版本按用户明确要求下载并内置了 Windows 适配版苹方，三套默认候选字体均可直接预览和应用。具体来源、固定提交、文件哈希及原始版权声明记录在 FontPackages/pingfang-sc；来源记录不等于新增字体授权，WinGlow 的 MIT 许可不覆盖字体。

## 一键体验与后续扩展

2026-10-03 用户补充：默认首页一句介绍与一个大的“一键优化”按钮。一次完成字体、右键菜单精简与美化、透明任务栏；完成后直接提供撤销。细分选项留在各功能类别，不要求用户理解注册表、渲染器或菜单扩展机制。

菜单自动策略优先清理第三方附加项目，保留重要系统和安全入口，隐藏项允许手动重新开启。百分比不是覆盖未知用途项目的依据；必须准确记录原值、失败回退、崩溃后恢复，不将优化前用户已有的设置误当成软件应清空的系统设置。

TranslucentTB 已得到本轮集成授权；其他热门工具先调研并列清单，只有用户确认后才考虑集成。候选清单见 customization-candidates.md。以上仍为产品方向；完成情况与实机验证边界以本版本验证记录为准。

## 3.2.1 验收调整

2026-10-03 用户确定：无既有选择时默认鸿蒙粗体，一键优化固定使用鸿蒙粗体，并纳入快捷方式箭头、盾牌角标的隐藏，透明任务栏、Breeze 美化及菜单精简。首页只保留居中介绍、优化及撤销操作。

菜单改为分类按钮、点击展开并缩进的子菜单，不保留右侧说明面板。自动操作名称为“一键精简”，扩大第三方附加项目清理范围，明确精简 Defender 扫描入口、全部百度/夸克网盘入口、WorkBuddy、图片转 PDF；这条用户要求覆盖先前“保留安全扫描入口”的默认策略，不影响防护功能。保留基本文件操作，不按固定比例随机隐藏；可恢复要求不变。程序动态生成的子菜单无法通过静态注册项逐个控制时，界面诚实提供整组开关。

## 3.2.2 验收原则

自动精简只减不加，必须保留手动关闭状态；扩大到 BitLocker 菜单、旧版 Media Player、华硕、ToDesk、英伟达、豆包、ChatGPT 项目入口。只修改菜单入口，不卸载驱动或改变磁盘加密。删除隐藏桌面图标文字选项。系统修改前必须自动备份，失败不修改；打开备份入口不向用户要求配置权限。

界面自身统一鸿蒙字体，2K/4K 高 DPI 适配在后台完成；首页标题不加句号，图标、标题和操作沿同一中轴，调整字距和视觉中心。任务栏默认模糊并显示细线。资源管理器刷新后保护已启用的美化组件，保留用户配置，不恢复已关闭的效果。

## 2026-10-10 开始菜单默认参数

用户验收确定：开始菜单背景浓度默认 20%，圆角默认 10。首次启用及一键优化共用此默认配置，已有自定义参数继续保留。窗口背景的界面说明应明确标题栏和应用露出的系统背景材质，不能承诺不透明应用内容也出现磨砂。
