# WinGlow 发展方向

记录日期：2026-10-03。以下为用户确定的产品方向，作为后续开发和功能取舍的依据；具体已实现功能以 README 和验证记录为准。

这个项目会以 **Windows 字体优化** 为核心，继续完善字体替换、渲染效果、预览和恢复体验。

后续会逐步扩展到更多 **Windows 视觉美化与个性化设置**，把字体、界面观感和常用美化选项集中到一个简单、安全、随时可恢复的工具里。

最终希望它成为一个轻量、好用的 **Windows 视觉调节工具**，让用户不用折腾复杂设置，也能把系统调成自己喜欢的样子。

## 开发原则

- 优先完善字体体验，再逐步扩展视觉美化与个性化功能。
- 界面保持极简，让用户直接选择、预览和应用，减少多余信息与操作。
- 每项系统修改都应有可靠的恢复路径；普通还原和必要时的扫描修复体验同样属于核心功能。
- 新功能应服务于轻量、简单、安全、可恢复的产品定位。

## 字体开箱即用要求

2026-10-03 用户补充：默认展示的候选字体应随软件内置，安装后即可预览和应用，不应要求用户另找字体文件。

3.1.3 本地版本按用户明确要求下载并内置了 Windows 适配版苹方，三套默认候选字体均可直接预览和应用。具体来源、固定提交、文件哈希及原始版权声明记录在 FontPackages/pingfang-sc；来源记录不等于新增字体授权，WinGlow 的 MIT 许可不覆盖字体。

## 一键体验与后续扩展

2026-10-03 用户补充：默认首页一句介绍与一个大的“一键优化”按钮。一次完成字体、右键菜单精简与美化、透明任务栏；完成后直接提供撤销。细分选项留在各功能类别，不要求用户理解注册表、渲染器或菜单扩展机制。

菜单自动策略优先清理第三方附加项目，保留重要系统和安全入口，隐藏项允许手动重新开启。百分比不是覆盖未知用途项目的依据；必须准确记录原值、失败回退、崩溃后恢复，不将优化前用户已有的设置误当成软件应清空的系统设置。

TranslucentTB 已得到本轮集成授权；其他热门工具先调研并列清单，只有用户确认后才考虑集成。候选清单见 customization-candidates.md。以上仍为产品方向；完成情况与实机验证边界以本版本验证记录为准。
