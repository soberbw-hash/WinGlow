## WinGlow 1.1.20

- Breeze 使用宽松主题、快速动画。简洁预设默认安装并开启 New+ 和右键菜单清理，已有插件可继续在 Breeze 中管理。首次下载的插件来自固定版本的 [Breeze 官方插件市场](https://github.com/breeze-shell/plugins/tree/1d3bc081b014f026e1a2c01a82cd50f0aa0ebc52)。
- 一键精简隐藏“用 Visual Studio 打开”和“兼容性疑难解答”。改完插件后可以点击“刷新菜单”，快速查看效果。
- “基础美化”支持统一刷新桌面。快捷方式箭头和盾牌使用新的透明图标覆盖，旧版开关需重新开启。Windows 或应用仍可能自行绘制盾牌。
- 手动选择 Rain 时使用与默认优化一致的任务栏颜色。壁纸切换失败时保留上一次有效的撤销记录。
