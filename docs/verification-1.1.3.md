# WinGlow 1.1.3 本地验收

2026-10-10，修复菜单关闭状态与实际显示不一致，并提供明确的美化用途和手动参数。

## 原因与修改

独立普通权限及管理员进程读到相同注册表，排除本次菜单问题由 Codex 文件目录虚拟化直接引起。实际桌面文件夹通过 `CMF_EXPLORE | CMF_CANRENAME | CMF_EXTENDEDVERBS` 查询时不含 WorkBuddy；再加入 `CMF_DISABLEDVERBS` 时会重新出现已经有 LegacyDisable 的 WorkBuddy、ToDesk、微信输入法等。此前 AppData 中的普通查询没有覆盖这条路径。Breeze 0.1.34 的源码另有模拟 Shift 的 Explorer 菜单兼容补丁；这并不证明所有动态扩展残留均来自同一标志。

新增 Breeze 显示前过滤：从实际 OFF 状态和本次修改后的状态生成受限标签规则，处理 WorkBuddy、百度/夸克、Defender 等动态标签与延迟子菜单。开关操作、精简、启用 Breeze 和应用启动同步都使用同一不可变备份事务。不开启隐藏项目，手动开启后解除相应规则；保留已启用同名注册项，云盘无品牌命令仅在两个相关提供者均关闭时过滤。继续保留压缩与解压。仅保留最近一次实际 Breeze 菜单的标签前后快照，不记录所选文件路径。

窗口功能更名“窗口背景”，明确它只设置支持窗口的系统材质，不把所有不透明应用变成磨砂窗口。新增云母/亚克力选择。开始菜单新增背景浓度 20–95%、圆角 0–24 和独立应用按钮，显示背景、圆角、局部鸿蒙字样的用途，不改布局。所有参数经后端范围校验、自动备份、激活失败回退；新后台记录实际应用材质，避免改为云母后还原仍假定亚克力。

## 补充复查

菜单显示过滤增加已启用标签的规范化保护，覆盖大小写、空格及快捷键标记差异，避免关闭项目误伤同名开启项目；三个新增 Rust 用例验证预测事务状态、关联来源及已启用标签保护，JavaScript 样例验证规范化冲突。对于同名但实际不同的命令，保护采取保守保留，不把标签相同视为已识别同一命令。

窗口材质与开始菜单参数分别使用自身保存值重置草稿，避免应用其中一组清掉另一组未保存的调整。Playwright 浏览器交互检查：开始菜单草稿 35% / 22 在应用窗口云母后保留；窗口亚克力草稿在应用开始菜单参数后保留且仍可应用。此检查使用仅在测试页面注入的 IPC 模型，不会修改真实系统，不能替代美化实际画面的验收。

复查修正版已重新签名打包、覆盖安装并打开。安装与便携 EXE 仅有 Tauri 包类型标记三个字节的正常差异（NSS / UNK），其余内容相同；全部发布文件与 SHA256SUMS 一致。启动后新规则脚本已经生成，Breeze 重载日志无脚本求值错误，美化组件继续运行。

## 恢复按钮修复

用户报告设置页红色提示内“去还原”没有反应。原因是按钮只切换到设置页，在该页面点击不会执行任何恢复。改为“恢复未完成修改”，直接调用恢复命令：首页、设置页及其他页面均可使用。处理中显示进度文案并禁止重复点击，结束后重新读取实际状态；授权取消或恢复失败时显示错误并允许重试。

新增专门的未完成恢复分支，只选未完成事务，按新到旧恢复；没有未完成记录时只重新检查状态，不回退已完成事务。先校验全部待恢复快照，损坏备份保持可诊断状态。原始值的恢复仍执行自动备份、写入验证及失败回滚；一键优化中断通过其原有配置与组件恢复流程处理。视觉组件和任务栏恢复在普通用户进程同步，随后刷新资源管理器。修复刷新成功覆盖前面的组件恢复警告的问题，保留原操作结果及警告。

本轮最终 Rust 76 项通过、1 项实际双重重启检查不重复运行；Clippy、TypeScript / Vite、菜单过滤检查通过。浏览器测试脚本 `scripts/Verify-RecoveryUI.js` 覆盖设置页成功、首页失败后重试、优化会话中断及过期提示；验证单次请求、处理中禁用、成功消除提示并解锁菜单编辑。测试注入 IPC 模型，不修改真实系统。另验证只选择未完成备份及排序，完成的备份不被标记撤销。当前读到的本机备份目录未发现未完成事务，未为验收故意制造用户设置损坏；故不能据此宣称已复现并恢复用户截图中的真实中断。

## 开始菜单默认参数调整

根据用户验收截图，将开始菜单背景浓度默认值由 78% 改为 20%，圆角由 16 改为 10；后端实际样式及浏览器预览同步。首次启用和一键优化仍共用 start_plan；已有自定义配置通过 appearance 读取保留。针对实际生成配置的测试验证 TintOpacity / TintLuminosityOpacity 为 0.20、CornerRadius 为 10，三个相关 Rust 测试、Clippy 及生产构建通过。窗口背景说明补充标题栏、系统背景和不透明内容的区别。
