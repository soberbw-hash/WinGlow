# WinGlow 3.1.4 右键菜单分类验证

日期：2026-10-03。本地测试版，未发布 GitHub Release。

## 本次变化

右键菜单页默认展示桌面类别，可切换文件夹、文件夹空白处、EXE、图片、文本、PDF、压缩文件、音视频、快捷方式及磁盘；“全部注册项”用于查看全体受支持的注册项。文件类型类别包含适用的公共文件菜单。桌面与文件夹空白处共享 Directory\Background 注册，归入两个位置，运行时条件由程序决定。

每行约 58px，名称旁显示右键位置与菜单层级。选中后再展示开启/关闭示意、作用范围、可读取的二级菜单。静态一级入口、静态级联入口和动态程序扩展分别标注，不将动态扩展假装成固定二级菜单。原始名称、开关用户范围和图标来源折叠保存；常见英文名称显示中文，未命名 GUID 扩展保留原始标识在详情中。JPG/PNG 等具体类型在列表副标题区分。Shift 和文件条件有可读说明。

图标优先读取注册的菜单图标，其次读取程序图标资源；缺失时使用占位图标。只读本地资源，不执行第三方菜单扩展。保留旧版 ID、开关存储位置、原值快照与分类还原机制；文件类型写入仍受固定路径白名单约束。内部 printto 与 ProgrammaticAccessOnly 命令不暴露为用户菜单项。

## 已通过的检查

- 29 项 Rust 测试通过，包含事务备份、原类型/不存在状态恢复、失败回退、字体、菜单路径限制、公共文件菜单继承、名称清理、资源索引/网络路径限制及真实 PNG 解码头检查。最终共享背景分类调整另运行对应继承测试，通过。
- Rust 格式、严格 Clippy、TypeScript 与 Vite 生产构建通过。
- 只读原生扫描得到 76 个受支持注册项：45 个静态入口、3 个级联入口、28 个程序扩展；31 项读到资源图标。数量取决于本机安装的软件，不代表一次右键会显示 76 项。
- 真实扫描中，桌面类别 19 项（含 13 个共享背景注册项）、EXE 24 项、文件夹 25 项。可读取 ArmouryCrate 的游戏库、Wallpaper Engine、Cyberpunk 2077 子菜单以及“文件所有权”的“个人”子项。
- Playwright 浏览器检查使用上述只读扫描 JSON，通过测试路由注入预览数据，生产代码没有添加模拟菜单。浏览器所有系统修改开关仍禁用。
- 1080×740 窗口能完整显示 9 行；760×600 最小窗口能完整显示 7 行。无页面或列表横向溢出，资源图标无加载错误。搜索 Cyberpunk 能找到其级联上级；开启示意有目标项，关闭示意没有目标项；空搜索结果正常。
- 构建 3.1.4 安装包、便携包与 SHA-256 清单到 artifacts/WinGlow-3.1.4；包内原生程序再次只读核验分类与字体恢复状态。
- 两个软件包与 SHA-256 清单一致；便携包 EXE 与已诊断的最终构建一致，官方图标原图字节一致，苹方来源/版权声明与品牌来源文件齐全。最终 EXE 版本为 3.1.4，三套字体 available=true，canRestore=true，无待恢复事务。

本地截图及扫描文件位于 WinGlow.App/output/playwright/，不提交仓库。

## 验证边界

未运行安装程序，未实际开关系统菜单或 Breeze，未加载第三方扩展来生成真实菜单。注册表枚举不覆盖所有关联类型、全部动态子项或 Windows 11 新式菜单。对比是开关效果示意，真实顺序、名称和可见性由 Windows、所选对象与程序运行时决定。扫描恢复状态不是一次真实恢复的验证。
