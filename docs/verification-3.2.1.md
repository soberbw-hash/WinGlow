# WinGlow 3.2.1 本地验收记录

日期：2026-10-03。基于用户对 3.2.0 的实机反馈；本版未发布公共 GitHub Release。

## 变化

- 无既有应用方案时选中鸿蒙粗体；保留已应用的显式选择。一键优化固定使用鸿蒙粗体。
- 一键优化增加快捷方式箭头和盾牌角标的隐藏，与字体、菜单、Breeze、透明任务栏配置同事务备份。
- 首页改为“让电脑更美观。”，移除底部三个分类入口，内容居中，保留优化和撤销。
- 右键页删除右侧说明栏，位置改为直接点击的分类按钮；静态子菜单展开并缩进，每个子项使用独立 ID/真实注册项开关。共享 CommandStore 子项状态影响引用它的菜单。动态程序扩展只提供整组开关。
- 更大的“一键精简”按钮。Defender 扫描菜单、百度网盘、夸克网盘、WorkBuddy、图片转 PDF 优先进入精简；保留基本文件操作和无法确认归属的项目，不以固定百分比随机删除。防护服务和安全策略不受修改。

## 已完成的验证

- cargo fmt --check、clippy --all-targets -D warnings 通过。
- Rust 44 项测试通过。新增隔离注册表测试：真实静态子项标签、禁用状态、嵌套路径、独立 ID 与保护基本操作。测试写入只位于唯一 Software\WinGlow\TransactionTests 路径。
- 字体、角标、静态子项、共享子项、引擎自启及配置不存在状态的组合备份：事务成功后撤销与激活失败回退均恢复 Fake ValueStore 的精确原始状态。
- TypeScript/Vite 生产构建通过。
- Playwright 使用只读本机菜单数据注入浏览器预览，所有系统修改按钮保持不可用：首页无底部入口，默认粗选中、标准仍可选，文件夹分类可直接切换，“文件所有权 → 个人”真实静态子项展开并缩进 28px；1080×740、760×600 无横向溢出，菜单列表可滚动。
- 浏览器截图人工查看：首页居中，菜单单栏与展开子项布局符合验收意见。

## 实机边界

本轮自动验证未执行字体替换、菜单禁用、资源管理器重启或恢复操作，不改变用户当前已应用的个性化设置。用户已经反馈前一版本整体效果良好；新版本新增的实际菜单显示/隐藏和组合撤销仍由此次验收确认。盾牌角标在部分 Windows 版本仍可能不响应通用图标覆盖。未声称静态枚举能列出实时 COM 动态子项或所有外部 ExtendedSubCommandsKey 类别。
