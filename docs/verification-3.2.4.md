# WinGlow 3.2.4 本地验收记录

日期：2026-10-03。本地测试版。

用户发现程序扩展项目可以展开，但只有说明文字，没有子项。MenuRow 原来根据 extension/cascade 类型显示箭头，现改为仅 subItems.length > 0 可展开；渲染同样以真实子项为准，避免数据刷新后残留空展开区域。删除空展开说明及其样式。整组开关保留，不伪造动态程序子项。

## 验证

TypeScript/Vite 通过。Playwright 浏览器注入既有本机只读扫描数据（76个顶层项目），检查73个无可显示子项的项目没有 aria-expanded 和箭头，3个真实子菜单逐一展开/收起后行数正确，包括两组各1子项的文件所有权菜单及3子项的 ArmouryCrate。搜索360压缩匹配1项目，展开按钮为0。没有空展开说明。人工检查菜单截图。

浏览器验证没有修改 Windows 菜单设置。此次仅调整前端展开判定和样式，不改菜单扫描或注册表写入逻辑，未重复运行会重启桌面的后端实机测试。

## 打包

3.2.4 NSIS 和便携版构建成功，两份包 SHA-256 校验通过，便携 EXE 与最终 release 一致，说明版本一致。已正常关闭旧版并打开新版 WinGlow 窗口，进程响应正常。未发布公共版本。
