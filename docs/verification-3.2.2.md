# WinGlow 3.2.2 本地验收记录

日期：2026-10-03。本地测试版，未发布公共 GitHub Release。

## 变化

- 首页标题去句号，调整字距；图标、标题、按钮统一中轴，内容组略高于几何中心。
- 应用自身使用内置鸿蒙；字体对比仍分别使用更换前/更换后真实字体。
- 菜单优先提取真实程序资源图标，未知图标按功能分类兜底，移除三横杠占位。
- 精简规则加入 BitLocker 菜单、旧版 Media Player、华硕、ToDesk、英伟达、豆包与 ChatGPT 项目入口；只隐藏，不开启之前关闭的项，也不改变磁盘加密、驱动或防护功能。
- 扩展名开关自动刷新 Explorer；移除桌面图标文字隐藏选项，保留旧备份恢复兼容。
- 打开备份改为后端固定目录命令，修复前端 opener ACL 错误。
- 所有受管理的系统设置变更先自动落盘备份；备份失败不变更。扫描前增加只读设置快照。
- 任务栏默认模糊并显示细线；刷新 Explorer 后重连已启用的自有组件。应用运行期间检测外部 Explorer PID 变化，有限重试；不启动已关闭效果，不改变用户配置。

## 验证

- fmt 检查、Clippy all-targets -D warnings 通过；49 项 Rust 测试通过。
- 新增自动精简“只减不加”、重复执行无新增操作、手动关闭父子项不恢复测试。
- 命令 EXE 图标解析：本地绝对路径、去掉参数，拒绝网络/相对路径和通用脚本宿主。
- 扩展名/分类还原刷新路由、刷新失败仍处理效果恢复、组合失败报告测试。
- 扫描前 checkpoint 保存确切设置而不写设置；既有备份失败时零写入、回退原类型和不存在状态测试继续通过。
- TranslucentTB 默认配置测试确认为 blur + show_line=true，固定归档哈希仍通过。
- TypeScript/Vite 和完整 Tauri/NSIS 构建检查。
- 只读本机菜单扫描证实用户列出的 BitLocker、旧版 Media Player、ArmouryCrate、ToDesk、NVIDIA、豆包、ChatGPT 项目入口 autoHide=true。
- Playwright 使用本机只读菜单数据：无三横杠占位，移除选项不出现，保留扩展名开关。真实资源图标与功能兜底同时显示。
- 六种逻辑视口 760×600、1080×740、1707×960、2048×1152、1920×1080、2560×1440：主页无横向溢出，图标/标题/按钮中心误差小于 1 CSS px。
- Chromium 仿真 2K @150% 和 4K @200%：devicePixelRatio 分别 1.5 和 2，无横向溢出。CDP 确认标题实际使用 HarmonyOS_Sans_SC_Bold 内置字体；非 CSS 名称推测。
- 人工查看首页与菜单截图。

## 实机边界

自动检查未实际切换用户扩展名设置、关闭菜单、执行系统修复或重启桌面。新版打开后的实际开关生效、打开备份和多次 Explorer 重启后效果由用户验收确认。2K/4K 为布局和 DPI 仿真，不声称已在两台物理显示器验证。运行时保护仅在 WinGlow 存在或其自身刷新操作中工作，退出后由上游组件自身负责。设置快照不是磁盘镜像，不能撤销 DISM/SFC 修复的 Windows 文件。快捷方式等系统特殊文件类型仍可能不显示后缀。
