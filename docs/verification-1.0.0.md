# WinGlow 1.0.0 验证

2026-10-04，重做版本基线。旧系列首次迁移需手动安装，之后使用签名自动更新。

- Rust：54 项通过，1 项会重启真实桌面的测试未重复执行；该实机测试在 3.2.3 已通过，刷新保护实现未修改。
- cargo fmt、Clippy（警告作为错误）和 TypeScript/Vite 构建通过。
- 原生只读菜单扫描：三个“设置为桌面背景”合并为一项。核对注册名称与执行命令，不仅按显示标题合并。合并开关在单一事务中控制各注册项。
- 删除显示扩展名、隐藏桌面图标和文字入口，后台也拒绝重新启用；恢复旧快照的兼容性保留。
- 自动精简保持只减不加；以前的版本、加密/解密、幻灯片加入明确规则。动态压缩扩展保留，Breeze 过滤脚本只删除现有多余压缩动作，不创建或重新打开入口。
- Node 菜单模拟验证：基本压缩/解压、非压缩操作保留；压缩/邮件等附加操作移除；动态子菜单同样执行；手动已隐藏动作不会补回。真实第三方菜单版本存在差异，实机逐项压缩操作尚待用户验收。
- Playwright 浏览器验证：已移除开关不可见；下载中不弹安装提示；准备好才提示；稍后关闭；手动再次打开；安装失败后可重试。此测试模拟更新接口，不修改 Windows 设置。
- NSIS 签名安装包生成成功，本地 Ed25519/预哈希签名和受签名版本注释验证通过，更新清单为无 BOM UTF-8。

发布后的公开清单、下载与签名诊断记录在用户数据目录 update-verification.json。该诊断只下载和验证，不安装。更新到一个后续版本的完整实机升级需要后续递增版本才可验收，不能由浏览器模拟替代。
