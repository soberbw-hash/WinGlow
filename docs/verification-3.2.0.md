# WinGlow 3.2.0 本地验证

日期：2026-10-03。字体双字重与原生界面设置、一键首页、菜单自动精简、独立透明任务栏合并为这一版本。未发布 GitHub Release，未运行安装程序。

## 实现与已验证内容

- 字体仍是三套，鸿蒙只有标准 400 与真实 Bold 700。前端后段正文通过 Chromium 的 CSS.getPlatformFontsForNode 确认选中 HarmonyOS_Sans_SC_Bold，自定义字体已加载；没有用合成粗体冒充字体文件。选择思源后两档控件消失。
- 更换前读取 Windows 当前 MessageFont 与字重。只读诊断：字体名称映射识别为 harmonyos-sc，而六个经典界面角色配置仍是 Microsoft YaHei UI、400、height -18，系统 DPI 144。旧版 UI 可以再次显示“应用”，不误报已应用；canRestore=true、无未完成普通事务。
- 新增原生 SPI 界面字体设置；六项持久 WindowMetrics 与实时字体快照同事务备份，保留字体尺寸与平滑字段，持久尺寸按 DPI 规范化。默认还原包含这两个范围。
- 一键首页有未优化、已优化且可撤销、上次未完成且可继续恢复三种状态。Playwright 使用只读诊断数据注入开发预览，系统修改按钮保持禁用；没有在生产代码添加模拟成功。1080×740 与 760×600 下无横向溢出；最小窗口的字体应用按钮可直接看到。
- 首页默认鸿蒙标准、菜单精简、Breeze 与 TranslucentTB。核心设置为同一快照，普通父进程启动引擎，完成标记最后写入；指定 UUID 快照用于撤销。核心、激活、完成标记失败都会触发恢复；恢复错误明确保留继续恢复入口。
- 一键优化不会假装把用户本来的第三方配置恢复成 Windows 出厂值；“撤销优化”恢复本轮操作前的状态。
- 本机只读扫描 76 个受支持菜单注册项，策略识别 14 个可精简附加项，包括 Git、豆包、360 压缩、ToDesk、微信输入法传送、WorkBuddy 等。Windows、Microsoft、安全扫描、核心操作和用途无法确认的项目保留。数量不是一次右键的项目数，也不是关闭固定 90% 的证明。
- TranslucentTB 官方 2026.2 x64 八文件压缩包已内附，SHA-256 与 GitHub release digest 相同：0dbe8e0255c20e131cde536dcd0ae490d45989a7d360e26d0150dff1922ac420。文件白名单与完整归档校验通过。独立配置、原字节与文件不存在状态均可备份恢复；关闭开关不会把历史中的本工具自启误恢复成开启。运行状态操作只面向完整路径匹配的本工具实例。
- 完整 Rust 测试 41 项通过，包含关闭开关不会重启历史自启值、配置校验无副作用且不会跳过后续条目等新增检查。覆盖真实字重、字体快照、普通事务失败回退、组合激活失败、回退失败提示、文件配置不存在状态与菜单原字节一起恢复、组件哈希等。主机测试仅读取原生界面字体或写临时测试键，没有应用主机字体/菜单/任务栏。
- 严格 Clippy、Rust 格式、TypeScript 与 Vite 生产构建通过。截图、只读 JSON 与测试脚本在 WinGlow.App/output/playwright，不提交仓库。
- 最终生成 artifacts/WinGlow-3.2.0 下的安装版与便携版，两个包均与 SHA256SUMS.txt 一致。便携 EXE 与最终只读诊断的 3.2.0 程序一致；ZIP 有 16 个条目，包含任务栏 GPL 与来源文件、使用说明及原始品牌图，品牌原图哈希一致。
- 最终程序只读诊断：四个逻辑方案对应三套字体，全部 available=true；needsFontRefresh=true、canRestore=true、无普通/一键未完成事务。六个原生界面字体与测试前相同。修正校验副作用后重新检查，测试夹具配置已转存到忽略输出目录，运行目录无任务栏配置文件；新增校验和组合事务测试再次通过且不重新创建该文件。

## 实机验证边界

没有执行 SPI_SETNONCLIENTMETRICS / SPI_SETICONTITLELOGFONT，没有实际启用/退出两个引擎、自动关菜单或重启本机 Explorer；实际一键应用、透明效果与完整撤销仍需 Windows 实测。子进程保持运行检查不证明真实视觉效果。此记录不把模拟值存储的事务测试描述成一次主机恢复。

原生字体设置改善经典字体选择路径，不把 NanoVG 渲染器扩展到全桌面，部分 WinUI/DirectWrite/UWP 自选字体仍不改变。Breeze 仍使用独立上游绘制与字体文件，不接管现有用户 Breeze 配置。透明任务栏使用官方 Windows 11 便携版；其他系统显示限制提示。一键撤销后的 Breeze 完整去除注入可能仍需注销。

其他候选工具只列在 customization-candidates.md，未安装、未自动下载或默认集成。
