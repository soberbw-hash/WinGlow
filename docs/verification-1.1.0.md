# WinGlow 1.1.0 验证记录

2026-10-05。本版本扩展右键分类与 GUID 识别库，同时加入精选视觉效果和两个独立可选工具。

## 已完成

- 格式检查、Clippy `-D warnings`、65 个 Rust 测试通过；独立的双次真实 Explorer 刷新测试保持显式忽略，本轮没有为了菜单重启桌面。
- TypeScript / Vite 构建通过，压缩菜单过滤测试通过。
- 本机只读扫描：77 项、53 个真实资源图标，包含此电脑、回收站、库及应用快捷方式。网络字典实际更新成功；离线字典与无效/部分下载保护测试通过。
- Playwright 使用只读本机扫描数据验证三层分类、显示/隐藏筛选、真实子项展开，在 1080×740、1707×960、1920×1080、760×600 CSS 视口下无横向溢出。浏览器预览不执行系统修改。
- Windows 11 build 28000 原生验证：Start Menu Styler DLL 实际加载；DWM API 0→3→0；独立后台进程对测试窗口应用磨砂，暂停恢复原值、再次启动恢复磨砂，启用配置保持不变；结束后精确还原新增配置和自启入口。
- Lively 与 ExplorerPatcher 官方固定安装包实际下载并匹配源码中的 SHA-256。配置树备份/恢复在隔离的测试注册表项中通过嵌套原始值往返验证。

## 实机验收边界

- 窗口磨砂使用官方 DWM 接口，主要作用于标准标题栏，不能保证改变应用自绘区域；没有集成 DWMBlurGlass 私有注入组件。
- 可选工具没有自动安装到测试机器；完整的安装/卸载、用户挑选壁纸、多屏和电池模式的视觉效果仍需用户验收。安装器控制参数按固定上游源码核对。
- 2K/4K 检查是常用 DPI 缩放对应的逻辑视口检查，不等同于在两台实体屏幕上的全部布局、应用字体与材质验收。

- 1.1.0 NSIS 安装包、独立更新签名、便携包和更新清单已生成，包文件 SHA-256 校验通过。静默安装完成，文件版本为 1.1.0。安装后 EXE 与便携构建仅相差 Tauri 的三字节安装类型标记（`UNK` / `NSS`），其余字节一致。
- 最终 Release 二进制再次通过原生视觉组件加载、暂停恢复和精确还原；菜单扫描及网络识别库更新再次通过。
