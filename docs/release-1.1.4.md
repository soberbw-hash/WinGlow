# WinGlow 1.1.4

## 更新

- 首页优化与撤销按钮等宽、等高，图标字号统一，保持介绍和操作区域居中。
- 开始菜单默认背景浓度 20%、圆角 10，保留已有自定义参数；窗口背景说明明确实际作用区域。
- 未完成修改提示直接执行恢复，支持首页恢复、失败重试和过期状态重新检查，只恢复未完成备份。
- 菜单显示过滤保护已开启的同名项目，兼容快捷键、空格和大小写差异；保留基本压缩与解压。
- 窗口背景与开始菜单参数独立保存草稿，避免互相清空；资源管理器刷新不再覆盖组件恢复警告。

## 验证

2026-10-10：Rust 76 项通过，Clippy / 格式检查 / TypeScript / 生产构建 / 菜单脚本检查通过。已有双重 Explorer 实机刷新用例此前通过，本次未重复重启桌面。恢复按钮的浏览器 IPC 模型检查覆盖成功、取消后重试、优化中断及过期提示。首页 1080×740、1707×960、1920×1080、760×600 的单按钮和双按钮八组检查通过：双按钮均 216×58，中心误差小于 1 CSS 像素，无横向溢出。

这些检查不能证明所有第三方动态右键菜单及所有应用的材质均发生可见变化；实际可见范围见 README 和 1.1.3 验证记录。签名安装包、便携包及更新清单使用一致的 1.1.4 版本。
