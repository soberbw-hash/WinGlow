# WinGlow 1.1.9

- 修复字体实时应用与重启后字号不一致的问题，保留用户原有字号；补充 100%～300% 缩放及 2K、4K 可用空间的回归检查。
- 首页移除重复的美化设置折叠区，统一按钮尺寸。基础美化页面使用单一滚动区域，避免多层滚动和底部大块空白。
- 动态壁纸加入一键优化自动轮播。在软件内部点击壁纸即可应用，提供导入、间隔、音量、暂停和恢复；暂排除已发现显示异常的 Parallax.js 项目。
- 在基础美化中调整任务栏效果与常用经典布局设置。经典布局保留系统兼容性限制，不在未验证系统上强行启用。
- 合并恢复流程末尾的资源管理器刷新，限制短时间连续重启，减少桌面效果组件受到的干扰。
- 升级优化失败时恢复本次升级前的配置；记录失败原因并暂停同版本自动重试，提供手动重试入口。
- 修复更新包下载完成后安装按钮的行为，并为桌面快捷方式使用独立图标资源。

验证：91 项 Rust 测试、严格 Clippy、格式检查、前端构建及压缩菜单检查通过；36 个首页布局场景通过。3 项专门实机测试未运行；实体多屏 DPI 切换及完整旧版升级流程不作为已完成验收。

Windows 10 / 11 x64。经典布局和窗口材质的可用效果取决于系统版本及应用窗口支持情况。第三方组件保持独立，设置修改可还原。
