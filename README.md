# WinGlow

**让 Windows 更好看，也更好用。**

WinGlow 把字体、右键菜单、任务栏、窗口背景和开始菜单集中在一个简洁的界面里。点击“一键优化”应用核心方案；动态壁纸是可选组件，核心优化完成后会询问是否下载约 218 MB 的引擎，也可以稍后在“基础美化”中安装。修改前自动备份，支持撤销、一键还原和分类还原。点关闭按钮隐藏到托盘，桌面效果继续运行。

## 功能

- **一键优化**：默认鸿蒙粗体，隐藏快捷方式箭头和盾牌角标，精简右键菜单，启用 Breeze、TranslucentTB 模糊与细线、窗口磨砂及开始菜单美化。核心方案先完成，动态壁纸引擎可在之后选择下载（约 218 MB），不会阻塞一键优化。
- **字体**：内置 HarmonyOS Sans（标准 / 粗）、思源黑体和苹方。选择、比较更换前后、应用。
- **右键菜单**：分为常用位置、文件类型、其他位置；补全此电脑、回收站、库和实际关联程序，支持按显示/隐藏筛选。显示程序图标；核对实际命令后合并重复注册，一个开关控制对应位置。只有真实可控子项才提供展开。
- **菜单识别库**：内置 ContextMenuManager GUID 字典，补充菜单名称及图标，随 WinGlow 版本更新。离线可用，不单独检查更新，不改变开关或自动执行菜单命令。
- **一键精简**：隐藏已识别的附加入口，包括网盘、Defender 扫描、以前的版本、加密/解密和幻灯片等。只减不加，不重新打开手动关闭项，不关闭杀毒防护或改变磁盘加密。
- **压缩菜单**：保留基本压缩、解压。对已识别的动态压缩动作，通过 Breeze 过滤多余入口；Breeze 关闭时该过滤不生效。动态扩展使用整组开关，不能逐项控制的内容不会伪装成独立选项。
- **基础美化**：任务栏默认在桌面、普通窗口、最大化窗口、开始菜单、搜索与任务视图中统一模糊并保留细线；另有窗口磨砂、开始菜单美化、快捷方式箭头、盾牌角标。盾牌效果取决于 Windows 版本，不关闭 UAC。
- **动态壁纸**：作为可选组件单独安装。首次一键优化完成后会提示下载约 218 MB 的引擎，也可从“基础美化”安装。安装后默认静音，可点击图片换壁纸或导入视频、动图；拨杆显示实际开启状态，关闭后再开启会恢复之前的选择。
- **恢复**：修改前自动备份，备份失败则停止。“一键还原”恢复 Windows 默认字体、按最早可用备份恢复菜单、恢复图标并关闭本工具管理的美化效果；保留可读字号，不改变显示缩放。另有分类还原、撤销最近修改，必要时运行 Windows 扫描修复。
- **托盘**：点叉号隐藏界面，单击托盘图标重新打开，右键可退出；重复启动只打开已有窗口。
- **自动更新**：启动检查，后台下载并验证签名，准备好后提示。点击安装并重新打开；也可以从“设置与还原”手动检查。

字体单独应用和还原可能需要刷新资源管理器，桌面与任务栏会短暂消失，文件夹窗口可能关闭。完整一键优化集中完成设置后再统一刷新；菜单切换、一键精简和菜单还原不主动重启桌面。刷新前暂停自有组件，桌面稳定后恢复已启用效果。部分应用需重新打开或注销才能使用新字体。

## v1.1.15 更新

- 核心一键优化不再同步下载约 218 MB 的动态壁纸引擎。
- 核心优化成功后显示下载提示；用户可立即下载，也可稍后从“基础美化”安装。
- 添加独立的动态壁纸下载状态提示。

## v1.1.14 更新

- 一键优化默认使用 Rain；手动点击图片切换，移除定时轮播及旧轮播后台任务。
- 新增“一键还原”，一次恢复默认字体、菜单及图标，关闭受管美化；与撤销最近一次修改分开。
- 点叉号隐藏到托盘，增加托盘打开/退出与单实例运行。
- 设置页新增作者主页和项目主页入口。
- 移除菜单识别库的独立更新入口与后台下载，识别数据随软件版本更新。
- 保留此前菜单操作不重启桌面、高 DPI 字体计算及恢复备份的修复。

第三方菜单与壁纸引擎仍受 Windows 版本及其他桌面工具影响。[检查记录](docs/verification-1.1.14.md)列出验证范围；不同电脑的实际效果可能有差异。

备份可从“设置与还原”打开。撤销恢复最近一次修改前的状态；一键还原按默认字体与最早可用菜单备份恢复，不能重置工具从未备份过的第三方设置。系统扫描修复可能需要联网和重启。

## 开发与发布

主应用为 `WinGlow.App`，使用 Rust / Tauri 2、React 和 TypeScript。根目录 C# 工程是历史实现，不用于新版打包。

```powershell
cd WinGlow.App
npm ci
npm run tauri dev
```

签名打包使用 `scripts/Build-ModernPackages.ps1`，更新密钥不进入仓库。[发布流程](docs/release.md)记录构建、签名和验证要求。
