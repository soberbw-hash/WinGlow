# WinGlow

让电脑更美观。以 Windows 字体优化为核心，把字体、右键菜单和常用美化选项集中到一个简单、可恢复的工具里。

## 下载

[下载最新版本](https://github.com/soberbw-hash/WinGlow/releases)。支持 Windows 10 / 11 x64，任务栏美化需要 Windows 11，应用需要 WebView2。

重做版本从 **1.0.0** 开始。旧系列首次迁移请手动安装新版；数据目录和恢复兼容标识继续保留，不删除旧备份。之后通过软件自动更新。

## 功能

- **一键优化**：默认鸿蒙粗体，隐藏快捷方式箭头和盾牌角标，精简右键菜单，启用 Breeze 与 TranslucentTB 模糊、细线效果。完成后可以撤销。
- **字体**：内置 HarmonyOS Sans（标准 / 粗）、思源黑体和苹方。选择、比较更换前后、应用。
- **右键菜单**：按桌面、文件夹、图片等分类，显示程序图标；核对实际命令后合并重复注册，一个开关控制对应位置。只有真实可控子项才提供展开。
- **一键精简**：隐藏已识别的附加入口，包括网盘、Defender 扫描、以前的版本、加密/解密和幻灯片等。只减不加，不重新打开手动关闭项，不关闭杀毒防护或改变磁盘加密。
- **压缩菜单**：保留基本压缩、解压。对已识别的动态压缩动作，通过 Breeze 过滤多余入口；Breeze 关闭时该过滤不生效。动态扩展使用整组开关，不能逐项控制的内容不会伪装成独立选项。
- **基础美化**：任务栏模糊与细线、快捷方式箭头、盾牌角标。盾牌效果取决于 Windows 版本，不关闭 UAC。
- **恢复**：修改前自动备份，备份失败则停止。支持恢复默认字体、分类还原、撤销最近修改，必要时运行 Windows 扫描修复。
- **自动更新**：启动检查，后台下载并验证签名，准备好后提示。点击安装并重新打开；也可以从“设置与还原”手动检查。

字体应用和还原会刷新资源管理器，桌面与任务栏短暂消失，文件夹窗口可能关闭。刷新前暂停自有任务栏实例，桌面稳定后恢复已启用效果。部分应用需重新打开或注销才能使用新字体。

备份可从“设置与还原”打开。撤销本次修改保留优化前的个性化设置，恢复默认字体则恢复 Windows 字体配置。系统扫描修复可能需要联网和重启。

## 开发与发布

主应用为 `WinGlow.App`，使用 Rust / Tauri 2、React 和 TypeScript。根目录 C# 工程是历史实现，不用于新版打包。

```powershell
cd WinGlow.App
npm ci
npm run tauri dev
```

签名打包使用 `scripts/Build-ModernPackages.ps1`，更新密钥不进入仓库。[发布流程](docs/release.md)记录构建、签名和验证要求。
