# WinGlow

**让 Windows 更好看，也更好用。**

WinGlow 把字体、右键菜单、任务栏、窗口背景、开始菜单和动态壁纸集中在一个简洁的界面里。点击“一键优化”即可应用默认方案；想调整细节，可以在对应页面直接设置。修改前自动备份，支持撤销和分类还原。

## 功能

- **一键优化**：默认鸿蒙粗体，隐藏快捷方式箭头和盾牌角标，精简右键菜单，启用 Breeze、TranslucentTB 模糊与细线、窗口磨砂及开始菜单美化、真实壁纸轮播。完成后可以撤销。
- **字体**：内置 HarmonyOS Sans（标准 / 粗）、思源黑体和苹方。选择、比较更换前后、应用。
- **右键菜单**：分为常用位置、文件类型、其他位置；补全此电脑、回收站、库和实际关联程序，支持按显示/隐藏筛选。显示程序图标；核对实际命令后合并重复注册，一个开关控制对应位置。只有真实可控子项才提供展开。
- **菜单识别库**：内置 ContextMenuManager GUID 字典，补充菜单名称及图标；每天后台检查，也可在设置中更新。离线可用，更新不会改变开关或自动执行菜单命令。
- **一键精简**：隐藏已识别的附加入口，包括网盘、Defender 扫描、以前的版本、加密/解密和幻灯片等。只减不加，不重新打开手动关闭项，不关闭杀毒防护或改变磁盘加密。
- **压缩菜单**：保留基本压缩、解压。对已识别的动态压缩动作，通过 Breeze 过滤多余入口；Breeze 关闭时该过滤不生效。动态扩展使用整组开关，不能逐项控制的内容不会伪装成独立选项。
- **基础美化**：任务栏默认在桌面、普通窗口、最大化窗口、开始菜单、搜索与任务视图中统一模糊并保留细线；另有窗口磨砂、开始菜单美化、快捷方式箭头、盾牌角标。盾牌效果取决于 Windows 版本，不关闭 UAC。
- **动态壁纸**：一键优化启用实际壁纸库的自动轮播，默认静音、每5分钟切换。点击图片直接换壁纸，也可导入视频或动图；拨杆显示实际开启状态，关闭后再开启恢复之前的选择，关闭 WinGlow 主界面后轮播继续运行。
- **恢复**：修改前自动备份，备份失败则停止。支持恢复默认字体、分类还原、撤销最近修改，必要时运行 Windows 扫描修复。
- **自动更新**：启动检查，后台下载并验证签名，准备好后提示。点击安装并重新打开；也可以从“设置与还原”手动检查。

字体单独应用和还原可能需要刷新资源管理器，桌面与任务栏会短暂消失，文件夹窗口可能关闭。完整一键优化集中完成设置后再统一刷新；菜单切换、一键精简和菜单还原不主动重启桌面。刷新前暂停自有组件，桌面稳定后恢复已启用效果。部分应用需重新打开或注销才能使用新字体。

## v1.1.13 更新

- 修复壁纸切换出现白底文字的问题，轮播使用真实壁纸项目，不再只切换纯色背景。
- 修复菜单精简造成桌面及动态壁纸闪断；菜单规则独立更新，减少脚本引擎反复重载。
- 改善高 DPI 字体换算及桌面字体缓存同步，保留更大的用户字号。
- 动态壁纸改为开启拨杆；删除多余播放控制、首页设置折叠区及经典布局功能。
- 修复初始化提示、恢复入口和设置保存失败的处理，保留旧备份兼容。

第三方菜单与壁纸引擎仍受 Windows 版本及其他桌面工具影响。本次本机验收通过，不代表所有电脑都完成实测；[检查记录](docs/verification-1.1.13.md)列出验证范围。

备份可从“设置与还原”打开。撤销本次修改保留优化前的个性化设置，恢复默认字体则恢复 Windows 字体配置。系统扫描修复可能需要联网和重启。

## 开发与发布

主应用为 `WinGlow.App`，使用 Rust / Tauri 2、React 和 TypeScript。根目录 C# 工程是历史实现，不用于新版打包。

```powershell
cd WinGlow.App
npm ci
npm run tauri dev
```

签名打包使用 `scripts/Build-ModernPackages.ps1`，更新密钥不进入仓库。[发布流程](docs/release.md)记录构建、签名和验证要求。
